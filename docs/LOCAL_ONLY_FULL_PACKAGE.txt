OpenCover Studio 私人跨电脑完整组件包
====================================

此目录由用户自己的开发机器环境组装，仅供同一位用户在自己的 Windows 电脑之间复制和合法使用，不能公开上传、出售或转发给其他人。

使用方法：

1. 将完整压缩包解压到短路径，例如 `C:\OCS`；不要直接在压缩包内运行。
2. 双击 `OpenCoverStudio-NVIDIA-Modern.exe`。不需要安装 Python、Conda 或 CUDA Toolkit。
3. 目标电脑需要 64 位 Windows 10/11、NVIDIA 显卡和足够新的 NVIDIA 驱动。当前只在 RTX 5070 Ti / CUDA 13 运行时完成实测，其他显卡不视为已经验收。
4. 首次启动会在包内创建 `workspace`；输出位于 `workspace\outputs`。

许可与功能边界：

1. 丰川祥子 RVC/DDSP、可可萝 DDSP 等社区模型的来源或再分发授权不完整，只允许本用户私人迁移。
2. Vevo2 权重采用 CC BY-NC-ND 4.0；GAME/部分声码器权重含非商业或相同方式共享条件；旧版 DiffSinger demo 权重未附独立模型/数据许可。
3. 丰川祥子 DDSP 已因真实歌曲质量验证不合格而在界面中停用；保留文件仅供历史复验，不代表可选择使用。
4. 改词翻唱仍是实验功能。当前祥子 RVC 对普通话吐字和部分音符落字存在已知听感问题，不宣称跨歌曲稳定。
5. 本包内各后端已嵌入便携 Python 基础运行时并使用相对目录，但另一台实体笔记本仍需实际验收后才能确认其显卡和驱动兼容。
