# 改词翻唱通用工作流

软件以用户认可的 C 流程为基线，自动完成吐字、旋律、句间音量和改词边界衔接处理。工作流标识为 `clear_c_v1`，固定使用 GAME + DiffSinger；默认原生中文歌声，优先吐字清楚。

## 用户操作

1. 上传原曲。
2. 填写或导入原歌词与新歌词，支持普通文本、TXT 和 LRC。新旧歌词按行对应，未改的行保留原词；同一句可以增减字词。
3. 选择音色、升降调、混音和输出格式，点击“开始改词翻唱”。

不需要 MIDI、词谱、音素、人工分轨或内部元数据。可先自动识别原歌词并校对。当前发音模型支持中文汉字；不支持的字符或无法容纳的字数会明确报错。

## 后台处理

| 阶段 | 自动行为 |
| --- | --- |
| 标准化与分离 | 统一音频格式，UVR5 分离人声和伴奏。UVR5 不可用则明确失败。 |
| 歌词定位 | 读取 LRC；普通歌词自动对齐原唱。只选出修改的短句，剔除外围伴奏空白。 |
| 旋律与发音 | GAME 提取音符，连续音高复核旋律，原唱逐字对齐后分配新歌词。保留原句时长、停顿和旋律，检查音素数量与发音时长。 |
| 歌声生成 | DiffSinger 一次加载、分句生成；同一字的转音使用连续元音，声学时长对齐词谱，声码器受完整旋律约束。 |
| 转音柔化 | 在连续有声音高内进行 35 ms 对数音高平滑，不跨越静音，不改变词谱节奏。 |
| 音色 | 默认原生中文歌声；用户选择 RVC/DDSP 时再转换，复用模型与已校验缓存。 |
| 句间音量 | 按演唱短句测量 LUFS，向各句中位数修正差值的 75%，每句最多 ±3 dB。每句保持固定增益，避免逐字自动增益造成抽吸。 |
| 边界衔接 | 合并相接的改词区间，自动遍历其外边界。从未改词间隙估计可靠伴奏增益，在改词区间内用最多 0.5 秒的平滑曲线衔接。5 ms 淡入淡出只作用于生成声部。 |
| 混音导出 | 改词区间不加回旧词和声；区间外复用标准化原曲。预留峰值余量并导出 WAV、FLAC 或 MP3。 |

边界增益估计只接收伴奏能解释超过 99.5% 原曲能量的窗口。相邻间隙不可靠时，使用同曲其他可靠音乐间隙的估计；全曲没有可靠参考则保持基础伴奏增益，并在任务结果提示重点试听。不会把原唱波形复制进改词区间。峰值余量不足时使用区间内固定衰减，并记录处理结果。

以上规则没有歌曲名、固定秒数或固定句数。试听样例中的 5–6 秒和 12–13 秒问题都由同一套边界规则处理。

## 结果与验证

任务目录保存自动词谱引用、修改区间、逐句响度增益、每个边界的参考可信度及峰值处理记录。`validation.json` 记录实际工作流版本。`audition` 下分别保留生成主唱、转换后主唱、均衡后主唱和最终混音，便于核对吐字与旧词残留。

WAV 混音在未改词区间保留标准化原曲采样；MP3 属于有损导出，不以逐采样一致作为要求。通过结构、时长、非静音和音高校验后仍需试听，技术指标不替代听感验收。

## 本机软件

项目根目录的 `OpenCoverStudio.exe` 与 `OpenCoverStudioWorker.exe` 使用项目内既有模型和后端。它们是本机源码项目的可执行入口，不能单独拷走作为便携包。

更新本机入口：

```powershell
.venv\Scripts\python.exe scripts\build_local_app.py
```

构建、缓存、临时文件和覆盖备份保存在项目 `workspace` 内，不修改第三方一键包。
