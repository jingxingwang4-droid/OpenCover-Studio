# 资源调研与阶段结论（2026-08-09）

## 已确认接口

- MSST 官方 `inference.py` 接受模型类型、配置、checkpoint、输入目录和输出目录；模型需另行选定并确认许可。
- RVC-Project 的新 CLI 提供 `rvc infer -m ... -i ... -o ...`，适合被独立 worker 调用。
- DDSP-SVC 官方 README 给出 `main_reflow.py` 非实时转换接口，并明确提到 Windows + Python 3.11 + CUDA 13 组合可工作。
- Vevo2 位于 Amphion，官方快速开始会自动下载多个 Hugging Face 权重；体积、中文/日语歌词编辑质量与 12GB 显存适配均未实测。
- GAME 官方推理可导出 DiffSinger 数据格式兼容的 MIDI/文本；DiffSinger 仍需合法歌声模型、vocoder、G2P 和音素表。

## 没有解决的问题

本次网络环境对 Git 远程查询超时，未取得可复现 commit。未下载大型权重，也没有选择身份和再分发权明确的丰川祥子模型。角色模型与试听可能涉及角色权利、声音权、训练数据授权和非商业限制；在来源不明确时不应下载或随包发布。

同样尚未找到满足“8–15 秒、真实无伴奏歌唱、许可明确允许再分发”的标准干声。项目因此保留目录和生成协议，但不放入合成音、空白 WAV、随机声音或其他模型试听作为替代。

## 发布门槛

每个后端转为“可用”前必须记录：固定 commit/tag、依赖锁、代码许可证、模型许可证与 SHA256、真实输入和真实输出的音频信息、运行命令、耗时、峰值显存、输出非静音检查和人工试听结论。
