## 改动

- 两条链路统一校验输出格式、升降调、混音和显存配置，在 GPU 推理前报告无效参数。
- 音频按块完整解码，检查有限采样值、数据完整性，并按用途检查非静音和时长。静音伴奏仍被允许。
- 原词转换与成品缓存不再只按文件大小判断；分离模型变化会失效下游转换缓存。FFmpeg 目录通过公共定位逻辑查找。
- 改词分离缓存校验可解码性；生成代码哈希在不同 Python 随机种子间保持一致，包括源码和冻结模块。切换音色能够复用同一份生成短句。
- 导出到唯一临时文件，验证后原子替换；失败保留既有成品。改词输出名包含完整任务目录的标识，避免不同目录同名任务相互覆盖。
- 任务启动失败、报告结果后异常退出、取消后迟到事件得到一致处理；结束状态按 ID 查询，不再受最近 100 条记录限制。完成信号发出前释放任务记录，方便连续调度。
- 桌面应用与离屏截图共用主题初始化，显式注册 Windows 中文字体，解决离屏中文方框。
- 新增 `scripts/accept_cover_workflows.py`，经 JobManager 调用真实 worker，留存输入、数据库、任务 ID、输出指标和未改词区间比较结果。
